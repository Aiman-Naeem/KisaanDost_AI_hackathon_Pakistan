The project is an Expo (SDK ~57) + React Native (0.86) application rooted at `App.tsx`, which wraps the UI in `NavigationContainer` and mounts the top-level `AppNavigator`. Navigation is split into two layers: `navigation/AppNavigator.tsx` defines a bottom-tab root navigator (`VoiceAssistant`, `Marketplace`) using `@react-navigation/bottom-tabs`, while `navigation/MarketplaceNavigator.tsx` nests a native stack (`ListingsScreen`, `AddListingScreen`) under the Marketplace tab via `@react-navigation/native-stack`. Screens live in `screens/` as stateless presentational components that compose reusable pieces from `components/` (currently `VoiceRecorder.tsx`, which uses `expo-audio`). Cross-cutting concerns are isolated in `services/index.ts` as a placeholder for API/AI integration, and shared UI primitives will be added to `components/index.ts`. App metadata, platform-specific icons, and the microphone permission plugin are declared in `app.json`.
